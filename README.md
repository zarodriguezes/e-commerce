# Sistema de Gestión de E-commerce

## Integrantes
- Zack Rodríguez 
- Miguel Menendez
- Wendy Pañora

## Descripción
Este proyecto consiste en el desarrollo de un sistema de gestión de e-commerce utilizando Go (Golang) y principios de programación funcional.

## Objetivo
Gestionar productos y procesar órdenes de compra mediante operaciones funcionales como filtrado, transformación y reducción de datos.

## Funcionalidades
- Visualización del catálogo de productos.
- Filtrado de productos por rango de precio.
- Aplicación de descuentos.
- Procesamiento de órdenes de compra.
- Cálculo del total de una compra.

## Conceptos de Programación Funcional Aplicados
- Filter
- Map
- Reduce
- Funciones de orden superior
- Inmutabilidad

## Tecnologías Utilizadas
- Go (Golang)
- Git
- GitHub

## Ejecución

go run main.go
